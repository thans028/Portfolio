# Student Portfolio Website

This is a starter portfolio website built as a single `index.html` file.

## Publish it free with GitHub Pages

1. On GitHub, create a **new public repository** named exactly `thans028.github.io`.
2. Upload `index.html` to the repository's top level and commit the file.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for deployment and visit `https://thans028.github.io`.

GitHub's official guide: https://docs.github.com/en/pages/quickstart

## Before publishing

- Confirm the education dates and degree wording.
- Add a professional email address and Handshake URL.
- Add Power BI report links only after reviewing public-access settings.
- The Community Health repository currently has a broad description; make sure its README accurately explains the analysis you completed. Do not call it a prediction/model project unless you built and evaluated a model.
- Replace or remove any content that is not accurate.

Power BI warning: "Publish to web" makes a report and its underlying data publicly accessible. Only use it for data you are allowed to publish publicly.
